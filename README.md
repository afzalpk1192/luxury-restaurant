# Luxury Restaurant Fullstack Project

This repository contains the **Luxury Restaurant** fullstack application.

Project directory: [luxury-restaurant/](./luxury-restaurant)
- **Frontend**: [luxury-restaurant/app/frontend](./luxury-restaurant/app/frontend) (React + Vite + Tailwind)
- **Backend**: [luxury-restaurant/app/backend](./luxury-restaurant/app/backend) (Express + Node + Mongoose)
- **MongoDB**: [luxury-restaurant/mongodb](./luxury-restaurant/mongodb) (Standalone MongoDB configuration)

### Quick Start
Double-click [start-all.bat](./luxury-restaurant/start-all.bat) inside the luxury-restaurant folder to launch MongoDB, backend, and frontend with a single click.
