# Standalone MongoDB Directory

This directory is set up to run MongoDB in standalone mode.

### Directory Contents:
- in/: Place mongod.exe here (portable MongoDB 8+ for Windows).
- data/db/: Storage folder for MongoDB collections and index data (ignored by git).
- start-mongo.bat: Batch script to launch MongoDB on port 27017.

### Running MongoDB:
Run start-mongo.bat or use standard MongoDB installed on your machine.
